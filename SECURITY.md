# Informações sensíveis

Os repositórios são públicos. Não publique credenciais, tokens, cookies, chaves privadas, configurações locais completas, bancos ou backups. Itens e caminhos classificados como sigilosos pertencem à base privada do inventário.

Ao relatar um problema publicamente, use uma reprodução mínima com dados fictícios. Encaminhe detalhes sensíveis à diretoria por um canal privado já utilizado pelo Ramo.

O código público não substitui a configuração do LLDAP, a proteção dos serviços internos, HTTPS e a revisão das permissões na implantação. A suíte automatizada usa apenas contas e diretórios efêmeros de teste.
